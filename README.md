# 🎮 FFICONS API

## 📦 Free Fire Item Icons – No Watermark, Fast Delivery

> **Created & maintained by [Shahil](https://github.com/Shahilali5)**  
> A simple, high-performance API to fetch clean Free Fire item icons using their in-game IDs.

---

## 🚀 Quick Start

### Base URL
```

https://cdn.jsdelivr.net/gh/Shahilali5/FFICONS@main/PNG/{item_ID}.png

```

Replace `{item_ID}` with the actual Free Fire item ID.

---

## 📌 Example

```

https://cdn.jsdelivr.net/gh/Shahilali5/FFICONS@main/PNG/907092607.png

```

### ✅ Response
Returns the icon image directly (PNG format).  
No watermark, no extra data – just the icon.

---

## 🛠️ How to Use

| Use Case | Method |
|----------|--------|
| Display in website/game panel | Direct `<img>` tag or CSS background |
| Download programmatically | `wget` / `curl` |
| Embed in bots/tools | Standard image URL |

## ⭐ Features

- 🔍 **Simple URL structure** – just append item ID
- 🖼️ **No watermarks** – clean icons only
- ⚡ **Fast CDN delivery** via jsDelivr
- 🔄 **Regular updates** – new items added periodically
- 🆓 **Completely free** – no API keys, no rate limits

---

## 📝 Notes

- Item IDs can be found inside Free Fire game files or community databases
- If an icon doesn't load, the ID might be invalid or not yet added
